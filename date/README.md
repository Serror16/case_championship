# Данные транспортной сети Чукотки

`transport_events_2026.csv` — основной вход расчёта: 29 142 направленные датированные дуги. Каждая строка означает, что в указанное время можно отправиться из `origin` в `destination` на одном рейсе или в рамках одного модельного подъезда. Время местное, UTC+12. Один физический рейс с несколькими остановками может давать несколько строк, чтобы поездка без смены транспорта не получала штраф 90 минут за пересадку.

| Поле | Значение |
|---|---|
| `event_id` | Уникальный номер строки; удобен для будущего исключения дуги в сценарии |
| `origin`, `destination` | Узлы графа, направление имеет значение |
| `departure`, `arrival` | Дата и время с часовым поясом ISO 8601 |
| `mode` | `flight`, `coastal_ship`, `ferry`, `bus_schedule_proxy`, `taxi_assumption` или `ice_road_taxi` |
| `service` | Номер рейса или название маршрута |
| `source_id` | Код строки в `sources.csv` |
| `evidence_status` | Качество исходного расписания или модельный характер строки |
| `assumption` | Текст конкретного допущения, если оно есть |
| `boarding_stop` | Номер начальной остановки в исходной авиационной цепочке, если применимо |

Значения `evidence_status`: `official_2026` — перенесённые авиарейсы из опубликованного расписания; `official_2026_transcription` — перенесённые прибрежные рейсы; `official_2026_duration_estimate` — переправа с оценкой длительности; `official_2024_schedule_proxy` и `official_2025_schedule_proxy` — более старые официальные часы, применённые к 2026 году; `secondary_2024_schedule_proxy` — часы из неофициального расписания; `model_assumption` — доступность или время заданы моделью. Это классификация качества **входных данных**, а не подтверждение исполнения каждого рейса.

`sources.csv` связывает `source_id` с названием, ссылкой и ролью источника. В нём есть также контекстные источники, которые обосновывают период работы, закрытия дороги или выбор перечня пунктов. Полное пояснение — в `SOURCES.md`.

`settlements.csv` хранит опорный перечень из 46 пунктов. `rated=1` означает, что пункт включён в пилотный расчёт (37 пунктов); `rated=0` означает недостаток маршрутных данных, а не доказанную недоступность. `source_id=S17` указывает на документ с перечнем.

`routes_2026.txt` и `settlements_2025.txt` сохранены как исходные расшифровки. Расчёт читает CSV, поэтому редактирование только этих TXT файлов не изменит индекс. Для нового или изменённого транспортного соединения нужна строка в `transport_events_2026.csv`; для повторяющегося рейса — отдельная строка на каждую дату. Обратное направление также задаётся отдельной строкой.

Все CSV записаны в UTF-8 с BOM для удобного открытия в Excel. Изменения входной таблицы можно проверить командой `python src/index.py`; результаты появятся в `results/`.
